# PolskiBot - System Zarządzania Społecznością Discord

PolskiBot to zaawansowany system integrujący bota Discord z profesjonalnym dashboardem WWW. Pozwala na pełną personalizację serwera, od automatycznej moderacji po zaawansowane systemy powitalne z grafikami generowanymi na żywo.

## 🚀 Główne Funkcje

- **Profesjonalny Dashboard**: Zarządzaj serwerem przez przejrzysty interfejs WWW (Flask).
- **System Powitań (Image Generator)**: Twórz unikalne grafiki powitalne z własnym tłem i podglądem na żywo.
- **AutoMod & Moderacja**: Chroń swój serwer przed spamem, linkami i niecenzuralnymi słowami.
- **Logi Audytu**: Śledź każdą zmianę na serwerze w dedykowanej zakładce.
- **System Poziomów**: Nagradzaj aktywnych członków społeczności.
- **Self-Role**: Pozwól użytkownikom wybierać role za pomocą interaktywnych paneli.
- **White Label (Custom Bot)**: Możliwość podpięcia własnej nazwy i awatara bota.

## 🛠️ Technologie

- **Backend**: Python 3.10+, Discord.py, Flask
- **Baza Danych**: SQLite3
- **Frontend**: HTML5, Vanilla CSS, JavaScript (ES6+)
- **Inne**: Pillow (generowanie obrazów), Aiohttp (API)

## 📦 Instalacja

1. Sklonuj repozytorium.
2. Zainstaluj zależności: `pip install -r requirements.txt`.
3. Skonfiguruj plik `.env` (TOKEN bota, Client ID, Client Secret).
4. Uruchom system: `python run.py`.
